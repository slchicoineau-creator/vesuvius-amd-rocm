## Root cause of the Stage 0 failure (all three rungs, same error)
`ValueError: no source shell rows pass quality bounds for shell_0001.tifxyz: target_step=200 bounds=(100,400)` (`init_shell_index.py:179`) in `fit.py`, because the shell from `cyl_init_tool.py` was degenerate: 3 x 64 vertices, row heights 219-245 but column widths `w_top` 0.8-5.1 vx (R=900; target 200), seed distance 1346 vx.
1. **The cylinder never touched the data.** `cyl_init_tool.py` always starts its first shell at radius 2000 vx (`model.py:394`, `cyl_shell_initial_radius = 2000.0`; no CLI or config switch; `tests/test_model_cyl_shell_scalespace.py:88` pins it). The registered ladder put the stand-in axis 900 / 600 / 1500 vx from the crop centre, so the radius-2000 cylinder passed 1100 / 1400 / 500 vx from it. The only prediction data on disk is the 128-snapped box x 4352-4736, y 3712-4096, z 9472-9856 (chunk files of `e2e_ref/pred_grad_mag.ome.zarr/1`: chunk indices z 74-76, y 29-31, x 34-36). In all three `cyl_*.log` the invalid-edge fraction (`ifrac`) is 1.0000 from step 0 to 1000: the shell optimiser saw no data, only regularisers, and the columns collapsed.
2. **Putting the cylinder on the data is not enough.** With the axis at R = 2000 the radius-2000 shell crosses the box, but only 1.6 % of its width edges are valid (`ifrac` 0.9841 at step 0). The 1000-step `cyl_init` stage (normal loss 0.57 at the valid points) then lowers its loss by moving off the data (`ifrac` 1.0000 by step 100-200, normal loss 0.0000), the shell ends 889 vx from the seed with widths 88-121 and the same ValueError follows. The cylinder-shell optimiser is built for predictions all around the circumference of a scroll; a 384^3 box cannot give it that.
- Failure class for `stage0.json`: **data** (prediction coverage too small for the registered shell step), not env / compile / diverged. Not a property of the FAST path.
